# UI Polish (Nav, Trust, Empty States) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship six concrete UI fixes identified in a full design review (sidebar navigation with active-state highlighting, consistent currency formatting, empty-state copy, a semantic "attention" color, artwork-card hover feedback, dashboard activity thumbnails), then prune `DESIGN.md` to remove sections copied from an unrelated product.

**Architecture:** Pure UI/presentation work on top of the existing Next.js App Router + Tailwind v4 + Shadcn stack. No schema changes, no new Server Actions beyond what already exists, no new external integrations. Two new design tokens are added to the existing `@theme` block in `src/app/globals.css`. One new pure utility function (`formatCurrency`) gets a unit test; everything else is verified by a manual dev-server walkthrough, consistent with how prior UI-only work in this codebase has been checked.

**Tech Stack:** Next.js App Router (Server Components), Tailwind CSS v4 (`@theme` token block), Shadcn UI, Vitest.

## Global Constraints

- No schema changes, no new Server Actions, no new external integrations — every task in this plan is UI/presentation only.
- New Tailwind tokens are added to the existing `@theme` block in `src/app/globals.css:51-66` (Tailwind v4's CSS-native token system — no `tailwind.config.js` in this project). Follow the exact naming convention already there: `--color-<kebab-name>` (e.g. `--color-electric-cobalt`), which Tailwind automatically exposes as `bg-<kebab-name>`, `text-<kebab-name>`, etc.
- Match existing code style: Server Components fetch data inline via `db`, scoped by `eq(table.userId, user.id)` on every query that touches a `user_id` column (this applies to Task 6, which adds a new query field). Client components only where interactivity requires it (Task 2's active-nav-state list, which needs `usePathname()`).
- Styling elsewhere uses only tokens already defined in `src/app/globals.css`'s `@theme` block, plus the two new tokens this plan adds (`--color-cobalt-wash`, `--color-attention`) — no other new colors.
- `text-red-600` (Tailwind's built-in red, not a project token) currently has two distinct meanings in this codebase: form-validation errors (8 usages — unchanged by this plan) and "overdue/needs attention" (2 usages — replaced by the new `text-attention` token in Task 5). Do not conflate these.
- Respect `prefers-reduced-motion` for any new hover/transition effect (Task 6 — artwork card hover).
- `DESIGN.md` pruning (Task 8) is documentation-only — it must not change any rendered UI. Do it last, once the tokens and components it documents actually exist.

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";

type NavItem = { href: string; label: string };
type NavGroup = { label: string; items: NavItem[] };

const NAV_GROUPS: NavGroup[] = [
  {
    label: "Studio",
    items: [
      { href: "/dashboard", label: "Dashboard" },
      { href: "/artworks", label: "Artworks" },
    ],
  },
  {
    label: "Clients",
    items: [
      { href: "/customers", label: "Customers" },
      { href: "/commissions", label: "Commissions" },
      { href: "/exhibitions", label: "Exhibitions" },
    ],
  },
  {
    label: "Money",
    items: [{ href: "/finance", label: "Finance" }],
  },
];

function isActive(pathname: string, href: string): boolean {
  return pathname === href || pathname.startsWith(`${href}/`);
}

export function NavLinks() {
  const pathname = usePathname();

  return (
    <nav className="flex flex-col gap-4">
      {NAV_GROUPS.map((group) => (
        <div key={group.label}>
          <p className="text-xs font-medium uppercase tracking-wide text-steel-gray px-3 mb-1">
            {group.label}
          </p>
          <div className="flex flex-col gap-0.5">
            {group.items.map((item) => {
              const active = isActive(pathname, item.href);
              return (
                <Link
                  key={item.href}
                  href={item.href}
                  className={`relative px-3 py-2 rounded-md text-sm font-medium ${
                    active
                      ? "bg-cobalt-wash text-electric-cobalt"
                      : "text-ink-charcoal hover:bg-canvas-cream"
                  }`}
                >
                  {active && (
                    <span className="absolute left-0 top-1/2 -translate-y-1/2 h-4 w-0.5 rounded-full bg-electric-cobalt" />
                  )}
                  {item.label}
                </Link>
              );
            })}
          </div>
        </div>
      ))}
    </nav>
  );
}
```
